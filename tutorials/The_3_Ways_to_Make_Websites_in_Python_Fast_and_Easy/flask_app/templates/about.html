About this app

This is a small task manager demonstrating the core features of Flask, a lightweight Python web framework.

  • URL routing with dynamic parameters
  • Jinja2 templates with inheritance
  • Static files (CSS)
  • Form handling (GET/POST) and flash messages
  • A JSON REST API at /api/tasks
  • Custom 404 error handling
